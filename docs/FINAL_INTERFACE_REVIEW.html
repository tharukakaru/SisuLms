What changed in this review

  • Removed the handwritten countdown font and its dependency. The countdown uses modern sans-serif typography and retains the purple, editable, removable layout.
  • Unified the application body and navigation with the locally bundled Manrope font; improved helper text, metadata, form focus and classroom tab spacing.
  • Removed social-media buttons with no configured destination. Real provider links remain available.
  • Fixed the blank Attendance tab: URL construction in the Vue template caused a rendering exception. The classroom register now renders correctly.
  • Fixed Settings preview loading and added local account controls with scoped enrolment visibility and tracked deletion-request behavior.
  • Corrected account-controls backend classroom filtering to reuse the shared active-class/role scope, preventing institute administrators from listing independently owned classrooms through this view.
  • Corrected singular classroom/student counts, supplied the missing delete icon, and removed irrelevant programme-invoice wording from standalone classes.
  • Removed remaining SOUL wording from the study-room introduction and account guidance. Provider billing guidance refers to the SISU Academy team.

Release decision

Ready for local design review; production acceptance still required.

This project includes frontend and backend source, but port 5182 is an isolated interface preview. Local tests use test doubles and cannot establish live banking, messaging, file protection, database migrations or deployment reliability. The changes improve consistency and usability; “award-winning” is a design ambition, not a verified award or quality certification.
