MOBILE DEVELOPER: REAL AUTH CONTRACT
Base URL: https://staging.sisuacademylk.com
RPC path: /api/method/institute_lms.<module>.<function>
Use TLS, Accept: application/json, Content-Type: application/json.
AppAuth authorize-only call opens system browser with:
GET /api/method/institute_lms.mobile_auth.app_authorize
client_id=sisu-mobile; response_type=code; code_challenge_method=S256;
code_challenge=base64url(SHA256(verifier)), without padding; state=random URL-safe
22-128 characters; redirect_uri=lk.sisulearning.app:/oauthredirect.
AppAuth validates callback state. Retain codeVerifier transiently. The callback is
allowlisted in il_mobile_redirect_uris on staging. No Frappe OAuth Client setup or
embedded client secret is required for this custom adapter.
Students must use Google in the browser. Authenticated browser consent POSTs
mobile_auth.approve with challenge,state,redirect_uri and valid browser CSRF.
Redirect includes code and state. Code is one-use and expires after 120 seconds.
Then, without browser cookies:
POST mobile_auth.exchange
{"code":"callback code","verifier":"AppAuth verifier","redirect_uri":"lk.sisulearning.app:/oauthredirect","device_id":"unique-device-session-id"}
verifier: 43-128 PKCE characters; device_id: 8-120 [A-Za-z0-9_-].
Response: {"message":{"access_token":"SECRET","token_type":"Sisu","expires_at":"server timestamp","site":"https://staging.sisuacademylk.com"}}
Subsequent requests use Authorization: Sisu <access_token>. Do not mix cookies or
Bearer tokens. Token expires in seven days; no refresh endpoint; restart requires
sign-in because this app stores tokens in memory only.
POST mobile_auth.logout {} returns {"message":{"revoked":true}}.
Invalid/expired/replayed/revoked tokens are rejected (401/403); no preview fallback.

LIVE CONTRACTS
POST live_classes.schedule {session}: class teacher; {message:{name:"live room ID"}}.
POST live_classes.control {name,action:"start"|"record"|"stop_recording"|"end"}:
named class teacher only, not arbitrary Institute Admin. Response
{message:{status:"Upcoming"|"Live"|"Ended",recording_status:"None"|"Recording"|"Processing"|"Ready"|"Failed"}}.
POST live_classes.join {name}: class access required, room Live;
{message:{url:"wss://...",token:"JWT",expires_in:120,can_publish:boolean,name,can_control:boolean,recording_status}}.
Pass JWT and URL to LiveKit client. Never log tokens. Student publish is disabled by
default. Joining does not grant server recording/admin powers.
GET live_classes.room_status?name=ID: {message:{status,recording_status}}.
POST live_classes.recording {name}: Ready recording and class access;
Student additionally needs recording_published. Returns {message:{url,expires_in:120,title}}.
Signed URL supports Range requests; renew through API when expired, never cache publicly.
POST live_classes.publish_recording {name,reviewed:true}: class teacher only, Ready;
{message:{published:true}}. Require an actual teacher review; do not auto-publish.
POST live_classes.reconcile {name}: teacher, only when provider outcome is uncertain.
Webhook URL: /api/method/institute_lms.live_classes.webhook (POST), LiveKit signature
required. Never call it with invented success events from the mobile client.
